anteriores de Valhalla SOC y se conservan como punto de partida y registro de la evolución del
proyecto. **No reflejan el estado actual:** para instalar y usar Valhalla, sigue el
[README](../../README.md), el [MANUAL](../../MANUAL.md) y [INSTALACION_PRIMERA_VEZ](../INSTALACION_PRIMERA_VEZ.md).

- `integraciones_rosa.md`: integraciones de IA (Rosalino Martínez).
- `CHANGELOG_VALHALLA.md`: registro de cambios de la Práctica 1.
- `img/`: capturas de la consola antigua.
